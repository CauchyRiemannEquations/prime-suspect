프라임 서스펙트 프로토타입 UI v2 검증 기록
검증 환경: Windows, Chromium 기반 미리보기 브라우저, Node.js 24

통과한 검증
- 원본 카드 수치 전체의 소인수분해 및 재곱셈 일치
- Case 1: 누락 인수, 홀수/짝수 지수, 환기구 논파
- Case 2: 유효한 일대일 스냅샷 배정이 정확히 하나임을 확인
- Case 2: 중복 배정 거절, 298,116 / 7,098 = 42 계산
- Case 3: gcd = 2,940, 스왑 후 592,900 / 298,116 복원
- Case 4: 1,763 + 1 및 1,009 - 1, 해치 경로 곱 1,008 검증
- 정답/오답/증거 누락/불필요한 증거/분석 미완료 판정
- 전체 4개 사건, 11개 추리 단계를 브라우저 UI에서 엔딩까지 플레이
- 새로고침 후 사건, 증언 홀드, 선택 증거, 계산 결과 복원
- 완료 사건 재수사 후 다음 사건 해금 유지, 새로고침 후 유지
- UI v2에서 4개 사건과 11개 논파를 엔딩까지 다시 플레이
- 기본 장면에 인물 하나와 증언 한 문장만 표시
- 다음 증언 → 잠깐 → 조사 → 증거 제시 → 짧은 결과 장면의 진행 확인
- 지도·디코더·증거를 한 번에 하나씩 여닫기, 배경 조작 비활성화
- 다른 카드를 분석한 뒤에도 심문 대상 및 홀드한 증언 유지
- 새로고침 후 증언 위치, 홀드 상태 및 분석 결과 복원
- 스냅샷을 한 장씩 배정하고 중복 배정 오류 및 정답 처리 확인
- 기존 v1 저장의 홀드 문장 복구, 사건 진행 및 해금 호환
- 전체 플레이 중 확인한 브라우저 경고·오류 로그 없음

검증 범위
브라우저의 file:// 접근 제한으로 파일 직접 실행을 자동 검증하지 못했습니다.
동일한 코드를 로컬 HTTP 미리보기에서 검증했습니다.
실제 iOS/Android 기기와 Safari/Firefox에서의 별도 실기기 검증은 하지 않았습니다.
이미지·음원은 임시 그래픽과 합성 효과음이며, 실제 전달 에셋 교체 후에는 다시 확인해야 합니다.

화면 확인: 1440x900, 1366x768 PC / 390x844, 320x740 작은 화면.
기본 장면의 증언은 1개이며 지도·디코더는 닫혀 있음을 DOM으로 확인.
320px 화면에서 가로 넘침 없음, Shift+Tab 도구 내 순환 및 Esc 심문 복귀 확인.
최종 단일 HTML 묶음의 시작·디코더·대화 복귀 확인.
