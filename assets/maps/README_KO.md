# Prime Suspect 청사진 SVG

실제 게임 cases.js blob `8e8fa8b1ec1656cf589cb521c8b94ba827f0fd1e`를 기준으로 한 960×720 정적 벡터 에셋 4개입니다. 투명 바탕에 청사진 격자와 어두운 노드/라벨 바탕을 사용합니다. 게임 코드·배포는 변경하지 않았습니다.

## 파일
- map_case1_blueprint.svg: 일반 연결 4개, 환기 덕트 5↔13. 소스의 실제 단서가 양방향 연결임을 명시합니다.
- map_case2_blueprint.svg: 일반 연결 4개. 존재하지 않는 11번 방이나 카메라는 넣지 않았습니다.
- map_case3_blueprint.svg: 일반 연결 6개. 중앙 휴게 라운지는 7입니다.
- map_case4_blueprint.svg: 일반 연결 4개, 해치 7→3 홀 내부. 외부 직통 탈출 경로가 아닙니다.
- 미리보기 PNG는 이 저장소 배치에서 제외했습니다. SVG 원본과 생성기/검증 데이터만 포함합니다.
- map-data.json: 실제 소스에서 추출한 지도 데이터.
- generate_maps.py: 외부 의존성 없는 SVG 생성/구조 검증 코드.
- VALIDATION.json: 노드·일반 간선·특수 간선 및 SVG XML 검증 결과.

## 인게임 연결 주의
이 파일은 이벤트를 처리하지 않습니다. HTML 버튼의 터치 영역·키보드 접근·조사 상태는 현재 게임 코드에서 유지해야 합니다. 노드 그룹에는 `id="room-N"`, `data-node="N"`, `data-name`을 두었습니다. 일반 간선에는 `data-from`, `data-to`가 있습니다.

Case 1과 Case 4의 특수 연결은 완성 도면에서 보이는 상태입니다. 플레이 시작부터 공개하면 단서가 유출됩니다. `#special-route` 그룹을 해당 단서(`vent` 또는 `hatch`) 조사 이후에만 보이게 하는 로직을 별도 연결해야 합니다. `data-requires-reveal="true"`는 메타데이터일 뿐 자동 숨김 기능이 아닙니다.

일반 선과 특수 선이 화면에서 교차하더라도 새 방이나 갈림길이 아닙니다. 실제 연결은 노드와 간선 데이터만 따릅니다. 단방향 화살표는 Case 4 비상 탈출 방향이며 일반 출입문은 양방향입니다.

한글 글꼴은 Noto Sans CJK KR → Noto Sans KR → 맑은 고딕 → sans-serif 순서입니다. 글꼴을 내장하거나 외부에서 가져오지 않습니다. 대상 기기에 한글 글꼴이 없으면 대체 글꼴/문자 표시를 확인해야 합니다. 제작 환경의 Inkscape 렌더에서 4개 도면의 한글·숫자를 육안 확인했습니다. 실제 모바일 게임에서의 크기·터치/탭 작동은 테스트하지 않았습니다.

모든 방의 이름·소수·좌표는 스냅샷에서 그대로 가져왔습니다. 아트 장식은 기존 연결을 추가하거나 바꾸지 않습니다.
