# Prime Suspect MVP 효과음 시안 v1

직접 합성한 절차적 효과음 프로토타입입니다. 외부 음원·녹음·상용 게임 샘플·멜로디를 사용하지 않았습니다. OpenAI 도구로 작성한 NumPy DSP 스크립트에서 잡음·사인파·비정수 배음과 감쇠 포락선을 합성했습니다.

## 파일
- sfx_card_swipe.wav: 0.48초. 걸쇠 클릭 → 짧은 마찰 질감 → 끝 클릭. 마그네틱 카드 읽기 시작용.
- sfx_factor_split_ok.wav: 0.66초. 음높이가 약간 올라가는 금속성 3연타와 마무리 착지음. 합성수의 분해 성공용. 소수 자체를 오류로 취급하지 않습니다.
- sfx_logic_break.wav: 1.35초. 원본 합성 저음 충격과 유리 파편을 연상시키는 비정수 배음. 정당한 모순 제시 성공용.
- PREVIEW_sequence.wav: 생성기를 실행하면 만들어지는 6.99초 청취용 묶음입니다. 저장소에는 중복 미리보기 파일을 제외하고 개별 효과음만 포함합니다. VALIDATION.json에는 제작 시 생성된 미리보기 검증도 기록되어 있습니다.

모든 WAV는 48kHz, 모노, 16비트 PCM입니다. 피크는 약 -8/-7/-7 dBFS이며 클리핑 샘플은 없습니다. 실제 재생 볼륨은 기기·게임 믹스에 따라 달라집니다. 이어폰과 휴대폰 스피커에서 낮은 볼륨부터 확인해 주세요.

## 검증과 한계
WAV를 다시 디코딩하여 샘플 수·길이·채널·비트 깊이·피크·RMS·DC·첫/끝 샘플을 확인했습니다. 같은 환경에서 생성기를 두 번 실행하여 SHA-256이 같은 것도 확인했습니다. 검증 결과는 VALIDATION.json에 있습니다.

음향 청취 도구가 없어 직접 청취하거나 전문 사운드 디자이너의 청감 검수를 하지는 못했습니다. 따라서 ‘자연스러운 실제 카드 마찰음/유리 소리’나 최종 상용 믹스 품질을 보증하지 않습니다. 저음 충격에 상위 배음을 섞어 작은 스피커에서도 인지되도록 설계했지만 실제 모바일 청취는 미검증입니다. 게임 이벤트 연결, 음소거 설정, 중첩 재생 제한, 브라우저 오디오 시작 정책은 아직 구현하지 않았습니다.

## 재생성
Python 3와 NumPy가 필요합니다. 이 폴더에서 다음 명령으로 동일 파일과 VALIDATION.json을 생성할 수 있습니다.

python generate_sfx.py

시드: 20261024. 파일명·시간·합성 성분·피크 목표는 스크립트에 명시되어 있습니다. 기존 출력 파일을 같은 이름으로 다시 만듭니다. 다른 NumPy 버전/플랫폼에서의 비트 단위 동일성까지 검증한 것은 아닙니다.
