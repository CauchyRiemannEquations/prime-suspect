# Prime Suspect 오디오 제작 2차: 독자 합성 시안

이 패키지는 음악·음향 디자인의 **절차적 합성 프로토타입**입니다. 파일 제작·기술 검증을 완료했으나 사람이 실제로 청취하거나 휴대폰/브라우저에서 재생해 본 결과는 아닙니다. 최종 상용 음원·전문 연주·실제 피아노/현악 녹음으로 표현하면 안 됩니다. 게임 코드는 수정하지 않았습니다.

## 구성과 재생 큐

### BGM: 각각 WAV 마스터 + OGG 배포 후보
| ID | 용도 | 구성 | 길이 |
|---|---|---|---|
| bgm_deep_sea_investigation | 현장 조사/지도 분석 | 72 BPM, 낮은 베이스, 느린 신스 화음, 간헐적 소나와 건반 | 40초 |
| bgm_interrogation_base | 일반 심문 | 96 BPM, 건조한 초침, 엇박 베이스 오스티나토, 절제한 화음 | 40초 |
| bgm_prime_pursuit | 결정적 모순 이후 추궁 | 140 BPM, 킥/스네어, 엇박 베이스, 독자 8음 모티프의 단계적 전개 | 약 41.143초 |
| bgm_trick_revealed | 전말 재구성 | 72 BPM, 배음 감쇠로 만든 피아노 유사 음색과 느린 현악 유사 신스 | 40초 |

직접 작성한 D 중심의 화성/모티프를 사용했습니다. 기존 게임의 곡·멜로디·편곡·샘플은 입력하거나 복제하지 않았습니다. 녹음된 외부 악기 샘플도 없습니다. 전개는 4마디 화성 순환을 기반으로 하며, 추궁 곡만 후반 리드 레벨과 리듬 밀도를 높입니다.

## 규격·검증
- WAV: 48,000 Hz, signed PCM 16bit. SFX 모노 / BGM 스테레오.
- BGM WAV 피크: 조사·심문·전말 −12 dBFS, 추궁 −9 dBFS. SFX −9~−23 dBFS. 타이핑은 더 작게 설정했습니다.
- WAV 클리핑 없음, DC 성분 확인. OGG를 다시 디코딩하여 샘플 수·피크·접합 경계를 검사했습니다.
- 음표와 잔향 꼬리를 루프 시작점으로 순환 누적하여 끊기지 않도록 제작했습니다. 파일 끝을 무음 페이드 처리한 단순 트랙이 아닙니다.
- WAV 경계 인접 샘플 차이는 약 0.002~0.003, OGG 약 0.003~0.006입니다. 내부 파형 변화보다 작은 범위라는 **수치 검사**이며, 이 수치만으로 청감상 무결점을 보장하지 않습니다.
- 실제 브라우저에서 OGG 디코더/재생 API가 gapless를 보장하는지는 별도 검증 대상입니다. 정확한 루프가 필요하면 디코딩된 AudioBuffer의 loopStart=0, loopEnd=전체 길이를 사용하고 휴대폰에서 확인해야 합니다.
- 여러 SFX 동시 재생 시 합산 클리핑이 발생할 수 있으므로 마스터 버스 헤드룸과 재생 빈도 제한이 필요합니다.
- 음소거·볼륨·사용자 제스처 후 오디오 시작·BGM 간 크로스페이드 연결은 아직 구현하지 않았습니다.

## 재생성·출처
`python generate_audio.py`로 동일 WAV를 재생성할 수 있습니다. Python 3, NumPy, SciPy, ffmpeg(libvorbis)가 필요합니다. 고정 난수 시드 20261025. 코드에 원래 작곡 음표·화음·큐를 모두 포함했습니다.

오실레이터·배음·필터링한 시드 노이즈만으로 직접 합성했으며 외부 음원, TTS, 모델 API, 유료 서비스, 계정 연결을 사용하지 않았습니다. OGG 컨테이너 직렬 번호 등으로 재인코딩 파일 해시는 달라질 수 있으므로 재현성 검사는 WAV 바이트를 기준으로 합니다.

VALIDATION.json은 개별 파일의 규격·해시·피크·접합 지표, QA_REPORT.json은 독립 재디코딩 및 재생성 검증 결과입니다. 최종 청감 승인과 실기기 검수 전까지 제작 상태는 `prototype_unlistened`입니다.
