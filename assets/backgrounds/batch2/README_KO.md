# 배경 추가 4종
OpenAI 이미지 도구로 생성. bg_title은 세로형, Case 2~4는 현재 인물 장면용 가로형 원본입니다. 정확한 크기는 VALIDATION.json 참고.
인게임 교정 기준: Case2는 침수/혈흔 대신 정전·익명 백업 단말기, Case3는 금고·망막 스캐너, Case4는 파괴된 서버가 아닌 냉각 제어실과 닫힌 내부 해치. 이름·숫자는 이미지에 넣지 않고 코드로 표시합니다.

검수 수정: 망막 스캐너는 3/5번 인증 게이트에만 있으므로 금고 13번 방 배경에서 제거했습니다. 아이템 스캐너 이미지와는 별도입니다.
