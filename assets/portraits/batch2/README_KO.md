# 추가 표정·주인공 원화

OpenAI 내장 이미지 생성/참조 편집으로 제작한 시안입니다. 기존 용의자 기본·당황 22장과 별도이며 이 폴더의 추가 파일 수는 MANIFEST.json을 따릅니다.

- 이름·역할은 실제 게임 기준, 외형과 표정 연출은 아트 제안입니다.
- 투명 PNG 고해상도 원본입니다. 512px 파생본, 실제 크롭 및 표정 전환 위치 검수는 별도입니다.
- 한도윤 붕괴의 안경 균열은 사용자가 요청한 연극적 표현이며 실제 사건 단서나 상처를 뜻하지 않습니다.
- 주인공은 실루엣·트렌치코트·단말기 제시로 표현하며 현재 게임에 슬롯 연결은 없습니다.
- PROMPTS.json은 재사용용 편집 지침을 재구성한 것이며 실제 원문 프롬프트의 완전한 기록이 아닙니다.
- 이 파일들은 게임 적용·배포 완료를 의미하지 않습니다.
