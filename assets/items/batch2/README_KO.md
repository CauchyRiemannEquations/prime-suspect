# Prime Suspect 단서 아이콘 추가 묶음

기존 매뉴얼·환기구를 제외한 9종 원화입니다. OpenAI 내장 이미지 생성 도구를 사용하고 기존 매뉴얼 이미지를 그림체 참조로 사용했습니다. 모든 PNG는 1254×1254 RGBA 투명 배경입니다. PNG 디코딩, 알파 범위, SHA256을 검증했습니다. 256px 최종 축소본과 게임 연결은 아직 수행하지 않았습니다.

## 포함 파일
- item_keycard_normal: 기본 마그네틱 카드
- item_keycard_1009: 백도현 카드. 표면의 작은 열 변색은 제안 장식이며 게임 단서 판정에 사용하지 않습니다.
- item_snapshot_log: 익명 백업 기록. 빈 세 줄.
- item_fluorescent_drain: 형광 시약 잔여물. 혈흔/수건 아님.
- item_retina_scanner: 신체 망막 인증 스캐너. 카드 소유자 인증과 구분.
- item_central_lounge: 중앙 라운지 위치 사진 형식의 상징 그림. 실제 촬영 증거가 추가된 것은 아니며 CCTV 사각지대 단서는 포함하지 않음.
- item_magnetic_coil: 역자기장 코일.
- item_aed_discharged: 방전된 제세동기. 인체 적용 장면 아님.
- item_escape_hatch: 내부 연결 해치. 외부/바다로 나가는 통로가 아님.

## 후속 연결 조건
카드의 정확한 1009, 백업의 21:05 및 150 / 1470 / 7098, AED의 0% 같은 의미 있는 숫자는 생성 그림에 넣지 않고 코드의 읽을 수 있는 텍스트로 표시해야 합니다. 빈 패널은 고의입니다. 소수라는 사실이나 홀수 지수 자체는 조작/유죄 증거가 아닙니다. 맵·단서 공개 조건과 연결 전에는 의미가 완성된 게임 UI가 아닙니다. 배경 없는 사물 아이콘은 실제 배치 위치를 확정하는 도면이 아닙니다.

전체 생성 프롬프트는 PROMPTS.json, 기술 검사는 VALIDATION.json에 있습니다. 저장소 반영은 별도 담당 단계이며 이 파일 자체가 업로드나 배포 완료를 뜻하지 않습니다.
