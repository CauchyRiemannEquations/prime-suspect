# Prime Suspect 에셋 제작·검수 체크리스트

## 확인한 내용

- 고해상도 래스터 파일은 실제 디코딩 후 크기·색상 모드·SHA256을 기록했습니다. 인물과 단서 PNG는 투명 영역과 불투명 영역을 가진 RGBA입니다.
- 추가 표정의 한도윤 붕괴, 강현우 계산적 미소, 정하늘 죄책감, 백도현 붕괴, 주인공 기본·지적 포즈를 직접 보아 표정 의도와 기존 복장을 표본 확인했습니다. 이전 검수에서는 단서 9종, UI 전체 아틀라스와 배경의 주요 설정을 확인했습니다. 모든 표정의 픽셀 위치 일치도를 수치로 보증하지는 않습니다.
- Case 3 금고실 13번 문 옆에 잘못 그려졌던 망막 스캐너는 제거됐습니다. 실제 망막 인증 위치는 서쪽 3번과 동쪽 5번입니다. 수정된 배경의 픽셀을 직접 확인했습니다.
- 최유리의 비정사 혈흔, Case 2의 혈흔·침수, Case 4의 외부 직통 해치·파괴된 서버 같은 잘못된 단서를 제작 기준에서 제외했습니다.
- 홀수 지수는 홀수 횟수 통과이지 단독 오류·유죄 판정이 아닙니다. 1009의 소수성 역시 정상 수학 결과이며, 기록 오염 판단은 단서 및 ±1 보정과 연결해야 합니다.
- 4개 지도와 40개 UI SVG는 XML 재파싱에 통과했습니다. 지도 간선·렌더 검증과 UI 렌더·모의 상호작용 검증 자료도 있습니다. 실제 게임의 터치 이벤트를 구현·검증한 것은 아닙니다.
- WAV 19개는 재디코딩했습니다. 기존 제작 검증에는 피크·DC·클리핑·루프 접합 수치 및 재현성 검사가 있습니다. 음원은 외부 음악·샘플을 복제하지 않은 절차적 합성입니다.

## 게임에 연결하기 전에 남은 작업

1. 오디오 청감·휴대폰 스피커·동시 재생·볼륨·BGM 전환 검수. 합성 악기 음색과 음악적 완성도는 아직 승인 전입니다.
2. 실제 브라우저·모바일 화면에서 인물 크롭, 표정 전환 위치, UI 터치·접근성, 배경 가독성 검수. 시연용 Chromium 실행은 소켓 권한 오류로 수행되지 못했으며 이를 통과로 기록하지 않았습니다.
3. 원본 보존 후 권장 512px 초상·256px 아이콘 등 파생본과 기기별 크롭·압축 최적화. 현재 일반 PNG 원화는 1254×1254이며, 배경은 가로 1672×941 또는 세로 940×1672입니다. 이는 누락된 그림 종류가 아니라 통합·성능 준비 단계입니다.
4. 지도 특수 경로를 단서 획득 후 공개하는 조건 연결. 완성 도면에는 Case 1 덕트 5↔13, Case 4 내부 해치 7→3이 이미 보입니다. 기본 플레이 화면에 무조건 공개하면 스포일러입니다.
5. 카드·로그·AED 그림의 빈 표시부에 1009, 150/1470/7098, 0% 등 정확한 숫자를 코드로 표시. 빈 표시부는 의도된 분리이며 단독 완성 텍스트 단서가 아닙니다.
6. 현재 단일 초상 슬롯에 표정 상태·주인공·챕터별 배경·사운드 이벤트를 연결하는 실제 게임 코드 작업. PR·병합·배포는 에셋 파일 제작과 별도입니다.
